# 小暖岛 · 今天也好好照顾自己

小暖岛是一个无需注册、适合手机和电脑使用的日常关照网页。你可以按医生说明建立每日用药计划，记录真实的服药时间，回看历史与最近七天的记录，也可以记下心情、电量和睡眠，做一分钟呼吸练习。页面保留温柔的配色与深浅主题，希望让照顾自己变成一件更轻松的小事，而不是增加压力。

**打开应用：** https://liufengyuan14.github.io/warm-island/

## 使用方法

1. **添加计划**：进入“我的每日用药计划”，点击“添加计划”，按已有医嘱填写药名、每次剂量、开始日期和每日时间；每天可设置 1–8 个时点。页面不会预设药物或推荐剂量。
2. **服药后打卡**：确认确实服用后，点击“确实已服用”，核对实际服药时间并保存。可以添加备注；如实记录“未服用”不代表建议停药。同一计划时点不会重复打卡。
3. **查看和补记**：在“服药记录”中选择日期，可查看历史、补记已有计划下的真实情况，或编辑、撤销误记。修改或暂停计划不会改写过去的记录，以界面显示的生效日期为准。
4. **设置提醒**：点击“生成日历提醒 .ics”，下载并确认导入手机日历，再检查事件、通知权限和声音；也可查看或复制时间清单，在系统时钟里手动设置闹钟。页面内提醒需单独开启，系统通知权限需由你主动申请，可用“测试提醒”核对。
5. **记录日常与保存备份**：心情、电量、睡眠和小关照都可以随手记录。定期点击“导出完整备份”并确认文件已下载；换设备可在正式网址导入备份，也可导出服药记录 CSV。导入会覆盖现有记录，并默认关闭页面内提醒，请先备份、再核对计划。

## 手机安装

- **iPhone**：用 Safari 打开应用，选择“分享 → 添加到主屏幕”。通知支持取决于系统版本，可能需要 iOS 16.4 或更新版本，并从主屏幕打开。
- **Android**：在支持的浏览器中选择“安装应用 / 添加到主屏幕”。
- 首次联网打开且离线缓存就绪后，可离线使用主要功能。安装到主屏幕不代表拥有系统闹钟权限或持续后台运行能力。

## 提醒限制与隐私

- **普通网页无法直接设置设备的系统时钟闹钟。** 页面关闭、锁屏、休眠或进入后台后，网页定时提醒不保证执行，不要将其作为唯一提醒方式。
- 日历文件覆盖生成日起未来 **30 个自然日**。导入方式和提醒支持因日历应用而异，需要在设备上确认并测试；更改计划时，先删除旧事件，再重新生成并导入，避免重复提醒。已打卡不会自动取消日历提醒，跨时区后也请重新核对。
- 日历默认不包含药名、剂量和备注；主动勾选显示后，这些信息可能同步至日历服务的云端。
- 个人记录保存在本机浏览器，不上传到 GitHub，不会跨设备自动同步，也未加密。清理浏览器、使用无痕模式或更换网站可能丢失记录；请勿在共用设备填写敏感信息，也不要把含健康信息的备份上传到公开仓库。本地预览与正式网站的记录不互通。

**本项目是记录与提醒工具，不是诊疗服务。未记录不等于未服药；不确定是否已服用时，请先核对，勿重复服药。药名、剂量、服用时点和漏服处理请遵循医生或药师的说明。**
